Engine Data

Reference SFOC at any load: SFOC(L) = SFOC₁₀₀ × (a + b × (L/100)²). Enter SFOC @ 100% MCR (shop trial). Optional SFOC @ 85% calibrates the curve; otherwise a = 0.25, b = 0.75. LCV correction: SFOCISO = SFOCmeas × (LCVref / LCVactual) — default LCVref = 42 700 kJ/kg.
Generator load % is calculated as (average kW ÷ max kW) × 100 for each alternator. Enter per-generator max kW from the nameplate.
Boiler and incinerator load % in supplementary reports uses the max kW values above.
Engine speed (kn) = RPM × Pitch(m) × 60 ÷ 1852. Engine distance (nm) = Pitch × Δrevs ÷ 1852 when the rev counter is available (including Δrevs = 0). RPM × pitch × 60 ÷ 1852 × hours is used only if Δrevs is unknown. Slip % = (Engine Dist − Ship Dist) ÷ Engine Dist × 100. %MCR / kW use the propeller law (RPM ÷ MCR RPM)³.

Bunker Consumption Calculation

Plan fuel burn by voyage leg for residual (HFO/LSFO) and distillate (MDO/MGO/LSMGO). Sea days auto-fill from Distance ÷ (Speed × 24) when Port/Anchor is unchecked (1 kn = 1 nm/h). Quantity = Daily Cons × Days. Required Quantity = Total Consumption + Margin %. Arrival ROB = Current ROB − Required (conservative). Next Departure ROB adds bunkers to be received.
Industry practice: sea days ≈ distance (nm) ÷ (speed kn × 24); port/anchor days are entered directly; a percentage safety margin (often 10–20%) is added to voyage consumption when sizing stems (many operators also keep a 48–72 h steaming reserve).

Performance Averages

Fuel Efficiency (SFOC)

Reference SFOC uses SFOC₁₀₀ from Setup and SFOC(L) = SFOC₁₀₀ × (a + b × (L/100)²). Estimated kW uses the propeller law (RPM/MCR RPM)³ × MCR kW — not a shaft torque meter unless Shaft kW is entered on Voyage Summary. When bunker LCV is set, ISO-corrected SFOC = measured × (LCVref / LCVactual). A sustained +3% deviation from reference often warrants investigation.

Machinery Running Hours (voyage)

Period totals from log / report hour-meters — useful for PMS planning. M/E hours = steaming periods with engine distance; A/E / boiler / incinerator from supplementary / voyage-summary runtime.

Departure / Arrival ROB Comparison

Opening ROB (voyage start / carryover) vs present ROB after all receipts and consumption. Print for end-of-voyage or port arrival handover.

Carbon Intensity & CO₂ (voyage estimate)

Attained CII ≈ total CO₂ (g) ÷ (DWT × distance nm). Cf: HFO 3.114, LSFO 3.151, MDO/LSMGO 3.206. Required CII uses a simplified year reduction from a 2019-style reference when ship type + DWT are set, or your manual override. Rating A–E is indicative only — confirm against IMO G5 guidelines / SEEMP Part III.

Remarks

Electronic Oil Record Book (e-ORB)

Guided MARPOL Annex I Oil Record Book logging (Part I machinery-space operations; Part II for tankers). Entry letter codes and item numbers follow IMO Appendix III. Flag selection loads administration guidance — official hard-copy replacement still requires flag-approved software under MEPC.312(74) plus a ship Declaration.

ORB Vessel Setup

Tank lists should match the IOPP Certificate Supplement (Form A/B). Flag administration determines language/approval notes shown while logging.
Rated capacities drive auto-ROB checks: incinerator quantity vs burn hours, and pump quantity vs start/stop time. Mismatches above the tolerance show a warning before save.

IOPP / ORB Tanks

Sludge / oil residue tanks = IOPP item 3.1 (weekly C.11). Oily bilge water holding = IOPP item 3.3 (voluntary weekly under Code I). Bilge tanks/wells = other bilge spaces for voluntary weekly Code I. Add cargo/slop/CBT when ship type is tanker. Frame no. should match the tank's position in the IOPP Supplement — it is carried into the ORB record wording and the printout.
